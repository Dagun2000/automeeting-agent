# 사내 용어집

## 구스엔진 (GooseEngine)
정확한 표기: 구스엔진
설명: 사내에서 자체 개발한 3D 게임 엔진. 현재 사내 모든 신규 프로젝트의
기본 엔진으로 채택되어 있다. 발음이 비슷한 "거스엔진", "구스언진",
"구슨진" 등으로 잘못 표기되는 경우가 많다.

## 나이트폴 SDK (Nightfall SDK)
정확한 표기: 나이트폴 SDK
설명: 구스엔진 위에서 동작하는 사내 조명·포스트프로세싱 툴킷. 다크판타지·
호러 톤 프로젝트에서 주로 사용하며, 동적 그림자와 안개 효과를 담당한다.

## 팰릿 파이프라인 (Palette Pipeline)
정확한 표기: 팰릿 파이프라인
설명: 아트 에셋을 자동으로 임포트·최적화해 엔진에 올려주는 사내 파이프라인
도구. 아티스트가 원본 파일을 특정 폴더에 넣으면 자동으로 압축·리깅
검증까지 처리한다.

## 에코 스트림 (Echo Stream)
정확한 표기: 에코 스트림
설명: 사내 오디오 미들웨어. 3D 공간음향과 다이나믹 BGM 레이어링을
담당하며, 구스엔진과 플러그인 형태로 연동된다.

## QA봇 (QABot)
정확한 표기: QA봇
설명: 매 빌드마다 자동으로 크래시·프레임드랍 구간을 탐지해 리포트를
올려주는 사내 자동 검증 봇. 사람이 아니라 내부 도구이므로 "QA봇이
그렇게 말했다"처럼 의인화해서 언급되는 경우가 많다.

## 렐름 컴파일러 (Realm Compiler)
정확한 표기: 렐름 컴파일러
설명: 레벨 데이터를 구스엔진이 읽는 바이너리 포맷으로 컴파일하는 사내
빌드 도구. 레벨 디자이너가 편집기에서 저장하면 자동으로 트리거된다.

## 홈베이스 대시보드 (Homebase Dashboard)
정확한 표기: 홈베이스 대시보드
설명: 라이브 서비스 지표(DAU, 매출, 크래시율)를 한눈에 보는 사내
라이브옵스 대시보드. 매일 아침 자동 리포트가 슬랙으로 발송된다.

## 트레일마커 로컬라이제이션 (Trailmarker Localization)
정확한 표기: 트레일마커 로컬라이제이션
설명: 다국어 번역 문자열을 관리·배포하는 사내 로컬라이제이션 툴. 번역가가
직접 문자열을 수정하면 빌드에 실시간으로 반영된다.

## 코쿤 세이브 시스템 (Cocoon Save System)
정확한 표기: 코쿤 세이브 시스템
설명: 클라우드 세이브·크로스플레이 저장 동기화를 담당하는 사내 프레임워크.
기기 간 세이브 충돌을 자동으로 병합하는 기능이 특징이다.

## 웜홀 넷코드 (Wormhole Netcode)
정확한 표기: 웜홀 넷코드
설명: 멀티플레이어 지연 보정(랙 보정)을 담당하는 사내 네트워크 코드
프레임워크. 실시간 대전 콘텐츠에서 필수로 사용된다.

## 시그넷 애널리틱스 SDK (Signet Analytics SDK)
정확한 표기: 시그넷 애널리틱스 SDK
설명: 유저 행동 로그를 수집해 홈베이스 대시보드로 전달하는 사내 애널리틱스
SDK. 이벤트 스키마가 바뀌면 QA봇이 자동으로 검증한다.

## 랜턴 비헤이비어 툴 (Lantern Behavior Tool)
정확한 표기: 랜턴 비헤이비어 툴
설명: NPC AI 행동 트리를 비주얼 노드 그래프로 편집하는 사내 툴. 기획자가
코드 없이 직접 몬스터 행동 패턴을 수정할 수 있다.

## 에코브릿지 리타게팅 (Echobridge Retargeting)
정확한 표기: 에코브릿지 리타게팅
설명: 서로 다른 캐릭터 리그 간 애니메이션을 재사용할 수 있게 해주는 사내
리타게팅 툴. 신규 캐릭터의 애니메이션 제작 시간을 크게 줄여준다.

## 던전스미스 생성기 (Dungeonsmith Generator)
정확한 표기: 던전스미스 생성기
설명: 절차적으로 던전·맵 레이아웃을 자동 생성하는 사내 툴. 규칙 기반
템플릿에 시드값을 넣으면 매번 다른 배치를 뽑아준다.

## 페블 매치메이커 (Pebble Matchmaker)
정확한 표기: 페블 매치메이커
설명: 실력·지연시간 기반으로 유저를 매칭하는 사내 매치메이킹 서버.
웜홀 넷코드와 함께 실시간 대전 콘텐츠에 사용된다.
